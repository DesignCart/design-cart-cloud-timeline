Sticky author biography with animated cloud timeline. Embed with shortcode.

== Description ==

Design Cart Cloud Timeline adds an admin cockpit with:

* Author bio (photo + rich text editor)
* Dynamic timeline entries (title, image via Media Library, content)
* Visual settings (colors, typography, animation) based on dc-cloud-timeline

Frontend layout: sticky author column on the left, animated cloud timeline on the right.

Shortcode: `[dc_cloud_timeline id="123"]`

Author: Paweł Nosko — https://www.designcart.pl/pawel-nosko.html
Company: Design Cart — https://www.designcart.pl/

== Installation ==

1. Upload the plugin folder to `/wp-content/plugins/`
2. Activate the plugin
3. Open **Cloud Timeline** in the admin menu
4. Create a timeline and paste the shortcode into a page
